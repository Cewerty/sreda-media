# Open Graph-превью материалов

**Версия:** 0.1 · **Статус:** черновик · **Владелец продуктовых уточнений:** Илья

**Основание:** [PRD](../prd.md), SITE-13 (Should), [ADR 0014](../adr/0014-cross-stack-content-contract.md).

## Результат и границы

При распространении ссылки на публичную страницу статьи или видео в Telegram и VK отображается превью с заголовком и изображением материала. Метаданные формируются при сборке статической страницы Astro из нормализованной публичной записи v1, независимо от источника данных (файлы или будущий API CMS).

## Правила формирования

| Тег | Источник и правило |
| --- | --- |
| `og:title` | `title` материала |
| `og:type` | `article` для `kind: article`, `video.other` для `kind: video` (по [Open Graph protocol](https://ogp.me/)) |
| `og:url` | Абсолютный канонический URL страницы материала на витрине, не ссылка `payload.url` на внешнюю видеоплощадку |
| `og:image` | Абсолютный публичный URL изображения, построенный из `cover.path` после разрешения и обработки медиа сборщиком |

- URL формируются на основе настроенного публичного origin сайта и фактических путей собранных страниц/изображений. В production указываются HTTPS-адреса; локальные URL, относительные пути и пути файловой системы не допускаются.
- Если у видео нет `cover`, используется единое доступное на витрине брендированное изображение Sreda Media. Отсутствующий файл явно заданной обложки или общего fallback — ошибка сборки, когда изображение необходимо. У статьи обложка обязательна по ADR 0014.
- Все обязательные теги находятся в HTML `<head>` уже после статической сборки и не требуют выполнения JavaScript или авторизации. Значения экранируются при HTML-рендеринге.
- Отдельное поле `social_image`, обязательное `og:description` и динамическая генерация OG-картинок в 0.1 не вводятся. Визуальный макет общего изображения согласует дизайнер с владельцем фронтенда.

## Критерии приёмки

| ID | Исходные условия и действие | Ожидаемый результат | Как проверить |
| --- | --- | --- | --- |
| AC-1 | Собрать статью с обложкой | Все четыре OG-тега в HTML, тип `article`, заголовок и изображение соответствуют записи | Проверить `<head>` собранной страницы и доступность изображения |
| AC-2 | Собрать видео с обложкой и внешней ссылкой | Тип `video.other`, URL ведёт на страницу витрины, изображение соответствует обложке | Проверить значения тегов и публичный URL |
| AC-3 | Собрать видео без обложки | `og:image` содержит абсолютный URL общего изображения Sreda Media | Проверить HTML и доступность fallback |
| AC-4 | Указать несуществующую обложку | Сборка завершается ошибкой, отсутствующее явно заданное медиа не заменяется fallback | Негативная проверка сборки |
| AC-5 | Поделиться ссылками на статью и видео в Telegram и VK | Превью содержит заголовок и подходящую картинку | Ручная проверка на доступном публичном адресе; учитывать кэш площадок |

Результаты проверки приложить к PR реализации. Общий DoD — [CONTRIBUTING.md](../../CONTRIBUTING.md).
