# Исследование: Vercel Preview Deployments для витрины

Статус: исследование завершено, настройка preview заблокирована отсутствием собираемого сайта в `main` (PR #16). Связано с issue #8, эпиком #9 и ADR 0006, 0007, 0014, 0015.

## Вопрос

Можно ли дать Сане и Полине ссылку на сборку конкретного PR (для ревью на компьютере и телефоне) в рамках бюджета проекта ≤500 ₽/мес и не нарушая обязательный Quality Gate в GitHub Actions?

## Что проверил

Официальная документация Vercel, прочитана 24.11.2026:

- <https://vercel.com/docs/plans> — обзор тарифов;
- <https://vercel.com/docs/plans/hobby> (обновлено 2026-11-12);
- <https://vercel.com/docs/plans/pro-plan> (обновлено 2026-09-15);
- <https://vercel.com/docs/deployments/environments> — раздельные environments для Preview и Production (обновлено 2026-09-17).

### Hobby (бесплатно)

Подходит для личного использования: 200 проектов, 100 деплоев в день, 2 vCPU / 8 ГБ на сборку, 100 ГБ Fast Data Transfer, 1 млн запросов CDN, 1 час логов. При превышении лимитов проект приостанавливается на 30 дней.

Командного сотрудничества и RBAC нет. Общий доступ участников к preview и комментирование сборок в тариф не входят — а именно это нужно Полине и Сане. Использовать Hobby для командного проекта нельзя.

### Pro

- Платёж **$20/мес** (≈2000 ₽ по текущему курсу) и 1 место «deploying seat» входит, дальше **$20/мес за каждого разработчика**. Viewer-места бесплатны (read-only + комментарии к preview).
- 6000 деплоев в день, 4 vCPU на сборку, RBAC, отдельные Preview/Production environments со своими переменными окружения.
- Платные аддоны: Password Protection $20/проект, SAML $300, Preview Deployment Suffix $100, Static IPs $100.
- Бюджет проекта ≤500 ₽/мес: Pro **не влезает** уже на базовом платеже (в 4 раза дороже лимита), не считая мест и аддонов.

## Ограничения проверки

- Учетной записи Vercel и прав на организацию `Sreda-Media` у меня нет — пробное развёртывание не выполнялось, ссылки на реальный preview приложить не могу.
- `apps/site` пока нет в `main` (PR #16 открыт), поэтому воспроизводимая сборка Astro ещё не может быть использована ни на Vercel, ни на VPS.
- Доступность из российских домашних и мобильных сетей не проверялась; отдельно нужно проверить после появления тестового адреса и при наличии тестового домена. Одна успешная проверка не гарантирует доступность у всех провайдеров.
- DNS финального домена ожидает Q-1 с Артёмом.

## Согласование с Quality Gate

Vercel не должен публиковать сборку, которая не прошла `ci`. При текущей конфигурации обязательный статус `ci` включён в ruleset `main-core-protection` (strict), а триггеры GitHub Actions на `pull_request` гарантируют, что красный PR не сольётся в `main`. Если подключать Vercel, его деплой должен запускаться только после зелёного `ci` и только из `main` (или быть явно помечен как preview, недоступный публично до прохождения проверок). Пока сайта нет, этот пункт остаётся проектным решением, а не проверенным фактом.

## Сравнение и рекомендация

| Критерий | Vercel Pro | VPS + Caddy (ADR 0006) |
| --- | --- | --- |
| Стоимость | $20/мес + $20 за разработчика, аддоны отдельно | Укладывается в существующий VPS ≤500 ₽/мес |
| Командный preview | Preview URL + viewer-места, комментарии | Нужен свой механизм (отдельный host/путь и контроль доступа) |
| Доступность из РФ | Не проверена; возможны проблемы с CDN | Зависит от провайдера VPS, проверяется отдельно |
| Rollback | Есть в интерфейсе Vercel | `scripts/deploy-static.sh rollback`, атомарный symlink по ADR 0015 |
| Эксплуатация | Внешний сервис, меньше поддержки | Свои скрипты и Caddy, уже описаны в `docs/DEPLOYMENT.md` / `docs/runbook.md` |
| Интеграция с CMS и same-origin | Требует отдельного решения | Соответствует согласованной схеме ADR 0006 (один origin) |

**Рекомендация для preview:** сначала сделать preview на VPS на отдельном тестовом адресе с помощью того же `scripts/deploy-static.sh` и Caddy; стоимость нулевая, механизм выкладки и отката уже написан и проверен локально. Vercel Pro не рекомендуется из-за стоимости и неподтверждённой доступности из РФ. Vercel Hobby для командного ревью не пригоден.

**Рекомендация для production:** оставить VPS + Caddy согласно ADR 0006. Изменение production-хостинга принимается Ильёй через новый ADR, это решение DevOps не принимает.

## Что осталось открытым

- Появление `apps/site` в `main` (PR #16) и реальная сборка Astro.
- Тестовый адрес и проверка доступности из российских домашних/мобильных сетей.
- Q-1 с Артёмом по DNS.
- Проверка, что preview на VPS не получает production-секреты и изолирован от production (отдельный `server_name`, отдельные каталоги, отдельные env).
- Пилотное развёртывание preview после снятия блокировок выше.

Refs: #8, #9, #16, ADR 0006, ADR 0007, ADR 0014, ADR 0015.
