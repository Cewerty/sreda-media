# Пробные карточки для GitHub Projects

Каждый раздел — отдельное issue. Владелец и версия предложены для полей доски. Результат проверки исполнитель прикладывает к карточке или связанному PR.

## Уточнить доступные DNS-записи у Артёма

Илья · 0.0 · Q-1, ADR 0006

**Результат.** Костян знает, через кого запросить настройку домена сайта и возможен ли отдельный адрес CMS.

**Контекст.** В. В. направил команду к Артёму. Сейчас требуется уточнение, изменение DNS будет отдельной работой.

**Критерии приёмки.** Зафиксированы контакт для внесения записей, ответ по основному адресу и ответ по поддомену CMS. Если решение по поддомену отложено, указаны ответственный и следующий шаг.

**Как проверить.** Костян сверяет запись в Q-1 или проекте ADR с ответом Артёма. В ожидании ответа карточка остаётся открытой.

## Подготовить мобильный макет страницы рубрики

Полина · 0.0, подготовка к 0.1 · SITE-04

**Результат.** Саня может сверстать общий список статей и видео по макету.

**Контекст.** Использовать сценарий и материалы из `docs/specs/site-04-rubrics.md`. Объём карточки — страница одной рубрики.

**Критерии приёмки.** На макете различимы статья и видео, виден порядок по дате, длинный заголовок читается на мобильном экране.

**Как проверить.** Полина прикладывает ссылку на макет. Саня сверяет порядок карточек со сценарием и отмечает в issue, достаточно ли макета для реализации.

## Добавить страницу 404 для неизвестного адреса

Саня · 0.1 · SITE-15

**Результат.** Читатель, открывший несуществующий адрес, видит страницу ошибки и может вернуться на главную.

**Контекст.** Нужна работающая сборка сайта и preview, на котором можно проверить отдачу статических страниц. Ссылка на главную — предлагаемый критерий этой карточки.

**Критерии приёмки.** Запрос к отсутствующему пути получает HTTP 404 и показывает страницу проекта. Переход по ссылке на главную открывает главную.

**Как проверить.** Приложить к PR адрес preview и результат запроса к заведомо отсутствующему пути. Ревьюер открывает этот путь и переходит на главную. После применимых проверок CI и независимого ревью PR вливается в main по CONTRIBUTING.md.
